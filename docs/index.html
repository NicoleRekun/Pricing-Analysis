Method

1. Win-rate model. For each segment, a logistic regression on the quote history: logit P(win) = a + b × (price ÷ lowest competitor − 1), fitted by maximum likelihood.

2. Objective. Expected gross profit per quote = P(win) × (price − unit cost). A higher price earns more per win but wins less often; the optimum balances the two.

3. Guardrails from internal policy. Never below the product class's margin floor, never above list price, and never more than × the lowest competitor price. When the floor sits above the competitor cap, the floor wins.

4. Before using it for real: validate on a hold-out period, run it beside analysts in shadow mode, and refresh competitor prices and model fits monthly.
